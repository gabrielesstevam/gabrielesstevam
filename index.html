Simulador de Loteria

...

Projeto universitário desenvolvido em Python com a biblioteca Tkinter, com o objetivo de criar um jogo de loteria por meio de uma interface gráfica. DashBoard Climático

...

Este sistema foi feito pra praticar JavaScript, principalmente trabalhar com fetch/API, organizar o código em módulos separados (um pra dados, um pra interface, um pra controle) e usar o LocalStorage pra salvar as cidades pesquisadas. O projeto é um dashboard do clima que busca informações reais de uma API (OpenWeather), e serviu pra estudar como montar a interface dinamicamente com JS, criar um sistema de tema claro/escuro, e lidar com erros de requisição. Também usei bastante CSS puro (sem framework) pra estilização, incluindo efeito glass e responsividade.
